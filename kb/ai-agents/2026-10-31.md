## arXiv: PCM: A Proof-Carrying Message Protocol for Verifiable Multi-Agent Communication
- We present Proof-Carrying Messages (PCM), a protocol in which each claim carries evidence: records from an append-only Merkle log that the agent cannot write, with inclusion proofs, signed by an attesting signer the agent cannot control.
- When one AI agent tells another that "the tests passed" or "a person approved this refund", the receiver has only the sender's word.
- A2A and MCP authenticate the channel, but the sender is the party in doubt, so a prompt-injected agent can launder fabricated facts and authority through a multi-agent system.
- Receivers check messages offline and give each claim a three-valued result: proven, unproven or failed.

**Why it matters:** Inter-agent protocol / communication contribution.
