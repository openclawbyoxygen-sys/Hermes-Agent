## arXiv: Do "True" and "False" Add Up to One? Complement Consistency in LLM-Agent Opinion Simulations
- In LLM-agent opinion simulations, each agent reports the probability that a claim is true after seeing its own previous probability and the probabilities reported by its neighbors, and that number becomes its state in the next round.
- If the number describes the agent's position rather than the sentence it was shown, then rewriting the claim as its complement and replacing every probability p with 1 - p should return the complementary answer, so the two reports should sum to one.
- We test this with three small open models: Qwen3-4B, Llama-3.2-3B and Gemma-3-4B.

**Why it matters:** Simulation-driven study — informs social-scale agent modeling.

## arXiv: HGWM: Hierarchical Graph-Guided World Model for Zero-Shot Object Navigation via Graph Matching
- Zero-shot object navigation requires an embodied agent to choose where to search while retaining evidence from previous observations.
- HGWM couples an LLM-generated room-anchor prior with persistent spatial-semantic memory.
- A coarse stage assigns visual-semantic scores to candidate headings on a 0-10 scale; a fine stage measures symbolic compatibility between observed objects, room context, and the goal prior.
- Phase-dependent fusion combines these scores with an LLM direction recommendation before local action selection.
