## arXiv: The Inbox as a Coordination Primitive for LLM Agent Societies
- First, push fails as an agent takes part in more coordination at once: an agent leading 20 negotiations with a full memory proposes options already rejected 97% of the time, because it has dropped the oldest replies.
- Language-model agents increasingly coordinate in large groups, and current agent protocols focus on delivering messages.
- For these agents, however, the scarce resource is not delivery but reading: every message costs tokens, and the context is finite.
- Current infrastructure works by push: the sender decides when a message enters the recipient's context, so the recipient reads in arrival order and drops the oldest messages once its context is full.

**Why it matters:** Directly relevant to LLM-agent practitioners designing new systems.
