## arXiv: Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents
- To address this, we introduce WikiTrace, an evidence-linked memory system designed to let agents check each lesson against its original trajectory.
- External memory enables LLM agents to improve from experience by distilling trajectories of past tasks into concise lessons for new tasks.
- However, memory can also lead to memory-induced degradation, where an agent fails on tasks it would solve without memory, often because it follows a lesson that is incorrect, or misapplies or misreads a valid one.

## arXiv: MultiTurnRoute: A Platform for Building and Evaluating Multi-Turn LLM Routers
- We introduce MultiTurnRoute, a platform for building and evaluating multi-turn LLM routers.
- In a multi-turn conversation, the choice of language model at one turn can affect which model should answer the next.
- The selected model's reply shapes the context for the next query, and its cached prompt prefix can reduce the cost of using that model again.
- A shared interface gives built-in and user-defined routers the current query, dialogue history, and an estimate of each model's reusable prefix length.
- Our routing algorithm, Chain-of-Route (CoR), uses a learned gate over recent and recurrent dialogue history to predict response quality and estimates cost from each model's reusable prefix.

**Why it matters:** Simulation-driven study — informs social-scale agent modeling.
